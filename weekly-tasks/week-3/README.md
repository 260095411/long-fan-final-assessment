## Introducing Python and working with data files: how interactions become data

## Workshop Context  
- **Unit**: MA Internet Equalities – Critical Coding Practices
- **Facilitator**: Ding Ding

This week we introduce how data is structured across different formats such as JSON and CSV. We introduce Python as the primary language for data processing and give example code of how a script can load, clean, and send data to website. You will understand how the languages of the Web, particularly javascript, are used to primarily handle data collection (such as capturing user interactions), visualisation on the page, and sending data to the back-end, while Python is used to actually store and process that data.
